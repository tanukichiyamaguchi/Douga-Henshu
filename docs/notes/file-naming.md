# 送るファイルの名前（2026-11-23）

送るファイル（完成した動画・見本・声の聞き比べ・バナーなど）に名前を付ける時に読む。決まりそのものは `CLAUDE.md` の
「既定値」の「ファイル名」。

## ユーザーが決めたこと（2026-11-23）

- 依頼の言葉: 「今後全ての動画のデータ名はもっとどの動画なのかわかるような名前にしてから出力してほしい。これは保存して」
- 形は、3 つの案（店名が先頭・日付が先頭・英数字だけ）から「日付が先頭」が選ばれた。
- 使う範囲は、「送るファイルすべて」と「動画だけ」から「送るファイルすべて」が選ばれた（完成した動画のほか、見本の静止画・
  声の聞き比べ・バナー・コマの一覧）。
- 直して送り直す時は版を上げ、同じ名前では送らない（選ばれた案の説明に書いていた）。それまでは、直した版を同じファイル名で
  送り直したことがあった（`docs/clients/kate-stage-lash-kamata-history.md`）。

## 形

`日付_店名_内容_形_秒数_v版.拡張子`

| 部分 | 書き方 | 例 |
|---|---|---|
| 日付 | 書き出した日を、日本時間の 8 桁で | `20261123` |
| 店名 | 依頼主の名前を短く。空白を入れない | `〇〇店` |
| 内容 | 何の動画か（メニュー・訴求）を短く | `まつ毛パーマ` |
| 形 | 縦横の比。`9x16`・`1x1`・`16x9`・`4x5`（「:」はファイル名に使えないので「x」） | `9x16` |
| 秒数 | 長さを整数に丸めて「秒」を付ける（20.7 秒 → `21秒`） | `21秒` |
| 版 | 送るたびに上げる。はじめは `v1` | `v1` |

例: `20261123_〇〇店_まつ毛パーマ_9x16_21秒_v1.mp4`（直して送り直す時は `…_v2.mp4`、同じ広告の 1:1 は
`20261123_〇〇店_まつ毛パーマ_1x1_21秒_v1.mp4`）。

動画のほかのファイル（形・秒数が当てはまらない物は、その部分を省く。版は必ず付ける）:

| 送る物 | 例 |
|---|---|
| 見本の静止画 | `20261123_〇〇店_まつ毛パーマ_見本A_v1.png` |
| 声の聞き比べ | `20261123_〇〇店_まつ毛パーマ_声の聞き比べ_v1.mp4` |
| バナー | `20261123_〇〇店_まつ毛パーマ_バナー_1x1_v1.png` |
| コマの一覧 | `20261123_〇〇店_まつ毛パーマ_コマ一覧_v1.png` |

## 付け方（Claude のやり方と解釈）

- 日付は日本時間で取る: `TZ=Asia/Tokyo date +%Y%m%d`。コンテナの時計は UTC なので（2026-11-23 に確かめた）、日本時間の
  0〜9 時に `date` だけで取ると、前の日になる。
- 書き出しは今までどおりの名前（`renders/out.mp4` など）で行い、送る前に、この名前でコピーを作って送る。Drive の
  `02_完成動画` に保存する時も、同じ名前にする（`create_file` の `title`）。
- ファイル名に使えない記号（`/ \ : * ? " < > |`）と空白は使わない。区切りは `_`。
- 同じ日に、同じ内容の別の案を並べて送る時は、内容の後に `A案`・`B案` を付ける
  （例: `20261123_〇〇店_まつ毛パーマ_A案_9x16_21秒_v1.mp4`）。
- 医院の動画のファイル名には、医院名が入る。医院名・地名はリポジトリのファイル・コミット・PR に書かない決まりなので、記録
  （`docs/`）にファイル名を書く時は、医院名の所を伏せる（例: `20261123_（医院名）_インプラント_9x16_22秒_v1.mp4`）。送る
  ファイルそのものの名前には、医院名を入れてよいと解釈した（送る先はユーザーだけのため）。
- 送る時の説明（SendUserFile の `caption`）にも、版と、前の版から直した所を書く。
