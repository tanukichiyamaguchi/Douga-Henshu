# フリーの BGM と効果音（効果音ラボ・OpenTracks）（2026-11-23）

BGM・効果音を選ぶ時に読む。決まりそのものは `CLAUDE.md` の「既定値」。道具は `tools/free_audio.py`。

## ユーザーが決めたこと（2026-11-23・24）

  2026-09-15 に名前が変わった）。
- 合う物が無い時は、勧めた「ElevenLabs で作る」が選ばれた。先にこの 2 つのサイトで探し、合う物が無い時だけ `gen_sfx.py`・
  `gen_music.py` で作る。どの音をどこから取ったかを、納品の報告に書く。
- この環境の通信先に、`soundeffect-lab.info`・`opentracks.com`・`dova-worker.tracks-cid.workers.dev`（OpenTracks が音の
  ファイルを渡すサーバー）を、ユーザーの承認を受けて足した。
- **18 歳以上に配信する広告（化粧品・美容施術。CLAUDE.md の「広告の決まり」）でも、効果音ラボの効果音を使う**（2026-11-24。
  3 つの案〔問い合わせる・使わない・使う〕から「使う」が選ばれた）。効果音ラボの FAQ の「グロテスク、ホラー以外で年齢制限が
  かかる作品へのご利用はすべてNG」は、アダルト作品の範囲を答える文の中にある。広告の年齢の絞り込みは、作品の中身でなく配信の
  決まりから来ているので、これには当たらないと読む（選ばれた案の考え）。サイトには確かめていないので、規約違反と言われる
  おそれは残る（案の説明に書いて選んでもらった）。

## 道具（`tools/free_audio.py`。`tools/` で実行）

| すること | コマンド |
|---|---|
| 効果音を探す（語ごとに探して、番号を付けて並べる） | `uv run python free_audio.py se キラキラ 決定` |
| 効果音を取る（同じ語で探し直し、その番号の音を取る） | `uv run python free_audio.py se-get キラキラ 決定 --pick 1,4 --out ../work/<作品>/assets/se` |
| BGM の検索タグの一覧 | `uv run python free_audio.py bgm-tags` |
| BGM を探す（ダウンロードの多い順。`--detail` で歌の有無・作曲者の条件・配信の言葉も） | `uv run python free_audio.py bgm --tag 明るい --tag ポップ --detail` |
| 曲の詳細（トラックごとの長さとループ、タグ、コメント、作曲者の条件） | `uv run python free_audio.py bgm-info 2445` |
| BGM を取る | `uv run python free_audio.py bgm-get 2445 --track 2 --out ../work/<作品>/assets/bgm` |
| 長さ・大きさ・帯域・鳴り始めと鳴り終わりを測る | `uv run python free_audio.py measure ../work/<作品>/assets/se/*.mp3` |
| 納品の報告に書く「音の出どころ」の表 | `uv run python free_audio.py sources ../work/<作品>/assets` |

道具がすること:
- リポジトリの中の、Git に入る場所には書き出さない（止める）。作品のフォルダ（`work/`）に置く。
- 取った音の横に `<ファイル名>.source.json`（どのサイトの、誰の、何という音を、いつ、どの条件で取ったか・測った数字・
  注意）を書く。`sources` は、これを集めて表にする。記録の無い音（ElevenLabs で作った物・ナレーション）も並べて知らせる。
- 取ったファイルは取り直さない。続けて読む時は 1 秒あける。
- 歌もの（タグにボーカル・コーラス）、作曲者の条件、コメントにほかの所での配信にふれた言葉、を知らせる。
- 許可されていない通信先に当たったら、その旨を出して止まる（環境の設定に足す提案をして、承認を受けてから使う）。

## 選び方（Claude の解釈。決まりではない）

- Claude は音を聞けない。名前・説明・タグ・ダウンロード数（多いほど、よく使われている）と、`measure` の数字で選ぶ。
  ユーザーが曲名や URL で指定してもよい。報告にはサイトのページの URL を書く（ユーザーがサイトで聞いて確かめられる）。
- 効果音ラボの検索は、名前と説明に、打った語がそのまま入っている物だけが出る。2 語を空白で並べると 0 件になる（「歓声 拍手」は
  0 件だった）ので、道具は語ごとに探して並べる。少ない時は言い方を変えて探す（「キラキラ」は 1 件だった）。1 ページ 30 件で、
  続きは `--pages` で読む。
- 効果音の意味の合わせ方（強調・驚き・訂正・きらめき など）は `docs/notes/reel-tips.md`。
- BGM は、ダウンロードの多い順に、動画の調子に合うタグ（`bgm-tags` の一覧から。例: 明るい・ポップ・軽快）で探す。
  タグを複数付けると、全部が付いた曲だけが出る。
- 歌なし（CLAUDE.md の BGM の決まり）: タグにボーカル・コーラスがある曲は、トラックの中身をコメントで確かめ、歌の無い
  トラックだけを使う。分からなければ使わない。
- 曲のコメントに、ほかの所での配信（TuneCore・ストリーミング など）が書いてある曲は避ける。2026-11-23 に、ダウンロードの
  とても多い曲のコメントに「TuneCore社を介して各種ストリーミングサイトでの配信準備中」とあった。音楽配信に出た曲は、配信の
  会社が音の指紋（Content ID など）を登録していることがあり、広告に権利の申し立てが来るおそれがある。
- 長さ: トラックごとに長さとループの可否が違う（`bgm-info`）。動画の長さに合わせて、切り出し・ループ・フェードをする
  （OpenTracks の規約で、イントロのカット・必要な所の切り出しとループの加工・フェードは可。下の「規約の要点」）。
- 大きさ: 2026-11-23 に取った BGM 2 曲は −10.5・−11.6 LUFS、山 +0.1・−0.9 dBTP と大きい。前の作品では、声 −14.5 LUFS に
  BGM を −28〜−30 LUFS 程度で混ぜていた（`docs/notes/production-log.md`）。そのまま置くと声が埋もれるので、下げて混ぜ、
  声との差を測る。
- 効果音ラボの効果音: 2026-11-23 に取った 4 本は、300Hz 未満が 0%（ElevenLabs の効果音で困った「低い音ばかり」は無かった）。
  大きさは −14.5〜−29.4 LUFS とばらつく。ファイルの長さと音の長さも違う（3.9 秒のファイルで、音は 2.0 秒で終わっていた）。
  `measure` で鳴り始め・鳴り終わりを見て置く。

## 規約の要点（2026-11-23 にサイトのページで読んだ。規約は変わるので、迷ったら読み直す）

### 効果音ラボ（https://soundeffect-lab.info/agreement/ ・ https://soundeffect-lab.info/faq/ ）

- 個人・法人・公的機関を問わず、商用も無料。報告・リンク・クレジットは不要（任意）。使用例に、テレビ番組・CM・YouTube
  （収益化しても可）が書かれている。海外での商用利用も可（FAQ）。
- 改変（ピッチ・カット・ミックス・速さ・音量 など）は可。改変した物を配る・売るのは再配布。
- 再配布は禁止。効果音が重要な役割を果たすコンテンツ（効果音だけを流す動画・効果音を紹介する動画・効果音を組み込んだ動画
  テンプレート など）も、再配布として扱う。
- YouTube ショート・TikTok・Instagram リールの、投稿した動画の音をほかの人が使える仕組みは、サイトが把握したうえで許可して
  いる（FAQ）。
- 禁止: アダルト作品・公序良俗に反する作品・違法行為への利用。FAQ では「グロテスク、ホラー以外で年齢制限がかかる作品への
  ご利用はすべてNGとお考えください」（18 歳以上に配信する広告の扱いは、上の「ユーザーが決めたこと」）。
- 禁止: 効果音のファイルへの直リンク、AI 学習用のデータとしての利用、効果音を使った音楽の Content ID への登録・音商標の登録
  など、ほかの人の効果音の利用に影響する恐れのある行為。
- 声素材: 声優の尊厳を傷つける・声優が被害を被る使い方は禁止。クレジットを書くなら「声素材提供：効果音ラボ」など（「出演」
  など、声優が作品に関わったと取れる書き方はしない）。
- YouTube で、誤って著作権の警告が出ることがある（FAQ。異議申し立てをすれば使える、とある）。サイトから消えた音も、消える
  前に取った物は使い続けてよい（人に渡すのは再配布）。
- 問い合わせのページがある（https://soundeffect-lab.info/c/ ）。

### OpenTracks（https://opentracks.com/help/articles/license/ ほか、license-usage・license-prohibitions・instagram の 4 ページ）

- 利用料なし。クレジットは不要（FAQ では「可能な限り記載をお願いします」）。個人・法人、営利・非営利を問わない。
- 動画の BGM は「背景音楽」としての利用に当たる（何か別の主となる物の背景〔従〕として使う。音源を主として使うのは、歌って
  みた などの「音楽作品における利用」を除いて範囲外）。例に、テレビ番組・CM・YouTube・TikTok などが書かれている。Instagram のページに「企業・ビジネスアカウントでの投稿・広告動画のBGMとしても無料でご利用いただけます」
  とある。
- 加工: ファイル形式の変換・エフェクト・イントロのカット・必要な所の切り出しとループの加工・フェード などは可。元の音源から
  乖離する、評価を著しく損なう加工は不可。
- 作曲者が別に条件を設けていることがあり、その時は作曲者の条件が先（利用料・表示〔クレジット〕・禁止事項は、サイトの
  ライセンスが先）。曲のページの作曲者の欄が「サイト準拠」でない時は、作曲者のページの条件を読む（道具が出す）。
- 禁止（抜粋）: 法令・公序良俗に反する制作物、政治・宗教などのイデオロギーの制作物、音源が主役の物（作業用 BGM など）、
  音源を配る・売る、受け取った人が音源のファイルを取り出せる形での利用、AI のトレーニング、作曲者の名誉や信用を傷つける用途、
  JASRAC などへの登録、音源や音源を使った制作物を、音楽として Content ID などの指紋の仕組みに登録すること。
- アダルトコンテンツは、法令に反しない物なら、作曲者の判断で使える場合がある（FAQ）。読んだ 4 ページには、年齢制限のある
  作品をまとめて禁止する文は無かった。
- 用途について、個別の許可・判断・問い合わせには応じない（自己責任で判断する、とある）。
- 同じファイルを続けてダウンロードできない（ダウンロードのページ「サーバ負荷軽減のため、同じファイルの連続ダウンロードは
  出来ません」）。
- 2026-11-04 のお知らせ: 2026-12-01（予定）に、無料アカウントと有料メンバーシップ（月額 550 円・税込・予定）を入れる。
  アカウントを作らなくても、検索・試聴・ダウンロードはこれまでどおり使える、とある。ページの作りが変わると道具が読めなく
  なることがある（その時は道具を直す）。

## はっきりしない所（決まっていない・確かめていない）

- **18 歳以上に配信する広告で効果音ラボを使うこと**: 上の「ユーザーが決めたこと」のとおり使うが、効果音ラボに確かめては
  いない。サイトから違うと言われたら、その広告の効果音を、ElevenLabs で作った物に替える（Claude の考え）。
- 依頼主の広告を作ること（受託）: どちらのサイトにも、受託についての文は無かった。CM での利用が例に書かれているので、使って
  よいと読んだ（Claude の解釈）。
- Meta の Rights Manager（音や映像の指紋で、権利の申し立てをする仕組み）: 2 つのサイトの音を使った広告に、申し立てが来るかは
  確かめていない。どちらのサイトも、音を使った作品を指紋の仕組み（Content ID など）に登録することを禁じているので、納品で、
  依頼主に「この動画を Content ID・Rights Manager などに登録しない」よう伝える（Claude の判断）。
- Claude は音を聞けない。どう聞こえるか（合うか・安っぽくないか）は、数字では分からない。

## 気を付けること

- 取った音はコミットしない（公開リポジトリに入れると再配布になる）。`work/` に置く（道具が止める）。
- 効果音ラボのファイルの URL（`/sound/…/mp3/…`）は、リポジトリの資料・PR・公開するページに書かない（直リンク禁止）。
  書くのはページの URL。ファイルの URL は、作品のフォルダの記録（`.source.json`）にだけ残る。
- 効果音を並べて聞かせるファイル（聞き比べ）は、ユーザーにだけ送り、Drive などで公開・配布しない（効果音だけを流す物・紹介
  する物は再配布に当たるため。Claude の解釈）。
- 取った音を、生成 AI のサービスに入れない（参考の音として渡す など）。どちらのサイトも AI の学習・トレーニングへの利用を
  禁止していて、入れた音を学習に使うサービスがあるため（Claude の解釈）。
- 曲を選んだら、そのページの作曲者の条件を、使う前に読む（変わることがある）。

  コメントの配信の言葉の知らせ、を本物のサイトで確かめた。
